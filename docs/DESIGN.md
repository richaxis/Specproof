# Design notes
Dark editorial fintech look inspired by twofold.fi: lowercase serif wordmark, mono uppercase eyebrows, headings that mix roman
and italic words, live "vault" panel, animated flow diagram, tile grid, stat row and table, large footer.
Palette: ink #08090b, cream #f1eee6, lime #c4f35a, amber #ffc247, coral #ff6b4a, violet #8b7bff.
Fonts: Instrument Serif, Inter, JetBrains Mono (Google Fonts).
